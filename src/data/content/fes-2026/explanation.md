# OMUCT Navi

大阪公立大学工業高等専門学校（OMUCT）の校内で、教室や施設を探して目的地までの経路を地図上で確認できるナビゲーションWebアプリです。

- **種別**: チーム開発(team !ms) / 高専祭向けWebアプリ
- **言語・環境**: TypeScript / HTML / CSS、Bun / Nix（flake）、GitHub Actions（CI）
- **主なライブラリ**: SvelteKit 3（Svelte 5）、Vite 8、Leaflet（地図描画）、Fuse.js（あいまい検索）、Tailwind CSS 4
- **テスト・品質管理**: Vitest（ブラウザテスト：Playwright）、ESLint、Prettier、svelte-check
- **デプロイ**: Cloudflare（adapter-cloudflare / Wrangler）

---

## 概要

大阪公立大学工業高等専門学校（OMUCT）の校内で、教室や施設を探して目的地までの経路を地図上で確認できるナビゲーションWebアプリです。
スマートフォンでの利用を想定し、ボトムシート型のUIで「探す → 選ぶ → 経路を見る」までを片手で完結できるようにしました。
高専祭での来場者案内にも使えるよう、トイレ・ゴミ箱などの施設検索にも対応しています。

## 主な機能

### 1. 階別の校内マップ

建物を選択すると階ごとのSVGフロアマップに切り替えられます。LeafletでSVGを重ね、建物・階の表示状態を管理しています。

### 2. 施設検索

教室や施設を名前・キーワードで検索できます。Fuse.jsによるあいまい検索で、表記ゆれがあっても候補を探せます。

### 3. A*による経路案内

出発地と目的地を選ぶと、校内のノード・辺からグラフを構築し、A*アルゴリズムで最短経路を探索して地図上に描画します。
建物や階をまたぐ場合は、階の移動箇所をマーカーで示し、経路上の階へ表示を自動で切り替えます。

### 4. バリアフリー検索

階段の辺を除外して探索することで、階段を使わない経路を検索できます。

### 5. 施設情報とPOIの強調表示

地図上の施設を選択すると所在地や説明を確認でき、そのまま出発地・目的地に設定できます。選択中・出発地・目的地は色分けして強調します。

### 6. 現在地表示と経路追従（GPS）

ブラウザの位置情報を使い、現在地と測位精度を地図に表示します。経路案内中は、経路付近にいるときだけ地図が現在地へ追従します。
位置情報は端末内でのみ処理し、外部サーバーへ送信しません。利用前にアプリ独自の同意ダイアログを表示し、拒否した場合も手動操作で使えるようにしています。

### 7. 高専祭向けの近隣施設検索

現在地（またはGPSオフ時は建物指定）から近いトイレ・ゴミ箱を距離順に最大5件表示します。トイレは男子・女子・バリアフリーで絞り込めます。
`src/data/config.ts`の`mode`を切り替えるだけで、通常版と高専祭版を切り替えられます。

### 8. 責務を分けた設計とテスト

画面・共有状態・経路探索・地図描画・データを分離し、検索パネルと地図は共有状態（`navigation`）を介してのみ連携します。
A*、グラフ構築、地図コンポーネント、GPS、施設検索などにユニットテスト・ブラウザテストを用意し、CIで自動検証しています。
