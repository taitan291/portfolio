# ソートアルゴリズム学習・比較ツール

Google Colab 上で動く、ソートアルゴリズムの「見て・測って・比べる」ための Python ツールです。6 種類のアルゴリズムをアニメーションで可視化し、実行時間や比較回数などの性能をインタラクティブに計測します。

- **種別**: 課題（Colab 課題04）/ 個人学習用ツール
- **言語・環境**: Python 3 / Google Colab
- **主なライブラリ**: matplotlib（アニメーション・グラフ）、ipywidgets（UI）、pandas（集計表示）
- **ノートブック**: [課題04_32-FT.ipynb](https://drive.google.com/file/d/1nTQzwjVNw9vu-YG5YJoKgazwJEpGblWk)

---

## 概要

ソートアルゴリズムは計算量（O(n²) や O(n log n)）を式で学ぶだけでは実感しにくい分野です。そこで、アルゴリズムの動きを 1 ステップずつアニメーションで確認でき、同じデータで実測した性能も比較できるツールを作りました。

## 実装したアルゴリズム（6 種）

| アルゴリズム | 計算量 | 特徴 |
|---|---|---|
| バブルソート | O(n²) | 動きが見やすい。最悪ケースの確認に向く |
| 選択ソート | O(n²) | スワップ回数が少ない |
| 挿入ソート | O(n²) | ほぼソート済みのデータで高速 |
| クイックソート | O(n log n) | 高速だが不安定 |
| マージソート | O(n log n) | 高速かつ安定 |
| スターリンソート | O(n) | 要素を削除して「ソート済み」にするジョークアルゴリズム |

## 主な機能

### 1. ソートの可視化
各ステップの配列の状態を記録し、matplotlib.animation で棒グラフとしてアニメーション表示します。アルゴリズムごとの動きの違いが直感的にわかります。

### 2. 性能計測
実行時間、比較回数、スワップ／削除回数を計測します。ベンチマークは複数回実行した平均・最小・最大を pandas の表で表示します。

### 3. インタラクティブ UI
ipywidgets により、コードを書き換えずに条件を変えて実行できます。

- テストデータの選択（ランダム／逆順／ほぼソート済み）
- データサイズ・試行回数のスライダー指定
- 実行ボタンによる動的なベンチマーク

### 4. グラフによる比較
平均実行時間・平均操作数の棒グラフ（色分け・数値ラベル付き）と、複数サイズでの折れ線グラフで、データサイズの増加に伴う変化を比較できます。
